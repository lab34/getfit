# GetFit

**Personal Weight Synchronization Utility**

## Purpose
**GetFit** is a private, personal-use application designed exclusively for its author to retrieve personal body weight measurements via Google Health / Google Fit APIs and process them via a local Python script.

## Scope & Access
* **Target Audience:** Single user (application owner only). Not open to public registration.
* **Data Accessed:** Read-only access to personal body weight records (`fitness.body.read`).
* **Hosting & Processing:** All data retrieval, execution, and storage occur exclusively on the owner's private local machine.
