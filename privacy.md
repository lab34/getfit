# Privacy Policy — GetFit

**Last updated:** November 2026

## 1. Overview
**GetFit** is a strictly personal, non-commercial utility operated solely by its developer for private use. This Privacy Policy describes how Google user data is accessed, used, and stored.

## 2. Data Accessed
Upon explicit OAuth 2.0 authorization by the account owner, the application requests read-only access to the following Google user data:
* **Body Weight Data:** Weight measurements and associated timestamps retrieved via the Google Fit / Google Health API (`https://www.googleapis.com/auth/fitness.body.read`).

No other Google account data (such as contacts, emails, location, or profile files) is accessed.

## 3. How Data Is Used
Accessed weight data is used **exclusively** to:
* Retrieve and log the owner's personal weight history using a local Python script on the owner's private machine.

## 4. Data Storage and Security
* Retrieved data is transmitted over encrypted HTTPS connections and processed/stored exclusively on the owner's local storage.
* OAuth refresh and access tokens are stored locally on the owner's private machine with restricted file permissions.
* No external cloud database, remote server, or third-party analytics service is used.

## 5. Data Sharing and Disclosure
**GetFit** does **not** sell, rent, trade, or transfer any Google user data or authentication tokens to third parties under any circumstances.

## 6. Google API Services User Data Policy Compliance
**GetFit**'s use and transfer to any other app of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## 7. Data Retention and Revocation
Data is retained only as long as needed by the owner for personal tracking. Access can be revoked at any time via the [Google Account Permissions page](https://myaccount.google.com/permissions), after which the application can no longer access Google data.
